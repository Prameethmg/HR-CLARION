# Contributing to HR Clarion

HR Clarion is an AI-driven human resources policy assistant designed to streamline HR inquiries and improve employee engagement. We welcome contributions to make the platform faster, more professional, and highly interactive.

## Current High-Priority Issues & Help Wanted

If you are looking for a place to start, we currently need help with the following issues and feature requests:

*   **Backend Performance Optimization:** The backend currently takes too long to analyze user questions. We need to optimize the processing logic and query handling to make response times as fast as possible.
*   **UI/UX Overhaul:** The current user interface needs a redesign. We want to move away from the current aesthetic and upgrade to a clean, modern, and professional UI. 
*   **Interactive Onboarding Feature:** We want to build a feature that automatically greets new employees when they join and asks them fun, interactive icebreaker questions (e.g., "What is your favorite pet?") to foster engagement among the team.
*   **Event RSVP & Polling System:** Add a feature for employees to create and respond to quick interactive event polls (e.g., a widget that says "Cycling on Sunday" with a clickable "Yes" RSVP button).

## How to Contribute

1. Fork this repository and create a new branch for your feature or bug fix.
2. Select one of the high-priority tasks above, or open a new Issue to discuss a different change.
3. Once your code is ready, submit a Pull Request with a clear description of the improvements you have made.
