# HR-CLARION

> HR-CLARION is an intelligent HR chatbot that helps employees navigate company policies like leave and work from home based directly on the employee manual. It also features a secure, dedicated reporting system for workplace grievances, allowing employees to report abuse, racism, or violence either anonymously or transparently.

## ✨ Features

*   **Policy Assistant Chatbot:** Instantly answers employee queries regarding leave, WFH, and other company guidelines based on your official employee manual.
*   **Secure Incident Reporting:** Provides a safe channel for employees to report serious workplace issues, including harassment, racism, or violence.
*   **Anonymous or Identified Submissions:** Empowers users with privacy control, allowing them to choose whether to remain anonymous or reveal their identity when filing a report to HR.
*   **Fully Responsive UI:** Built with modern design principles ensuring compatibility across all devices.
*   **Built-in Internationalization:** Seamless multi-language support via `i18next`.

## 🚀 Tech Stack

*   **Framework:** [React](https://react.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
*   **i18n:** `react-i18next`
